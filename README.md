# 水凝胶参考图重绘文件

- `hydrogel_excel.xlsx`：16 个数值页与 16 张可编辑 Excel 图表。
- `hydrogel_figures_300dpi.zip`：Figure 1 A–K、Figure 2 A–L，共 23 个 TIFF 分面，以及 Excel、绘图脚本和素材。TIFF 为 300 dpi、RGB、LZW 无损压缩。
- `SHA256SUMS.txt`：下载文件完整性校验。

## 来源与使用限制

所有数字来自对参考截图的视觉估读或为匹配图形趋势而做的示意构造，并非原始实验数据。误差棒不代表测量得到的 SD、SEM 或置信区间；无原始重复数或可支持的统计显著性。

照片、SEM 和 Western blot 为生成的示意重建，图内已明确标注。所有文件仅供版式、教学或示意展示，不可作为真实实验结果。

## 下载

点击 Excel 或 ZIP 文件，再使用 GitHub 文件页面的下载按钮（Download raw file）。ZIP 下载后解压即可获得分面 TIFF。
